## Accounting Helpdesk AI Chatbot

---

## Problem Statement
Accountants frequently answer repetitive questions.
This project automates accounting support using AI.

---

## Objective
- Build an AI chatbot
- No APIs, No LLMs
- Real-life usable system

---

## System Pipeline
User Query  
→ Preprocessing  
→ TF-IDF Retriever  
→ Neural Network  
→ Answer

---

## Dataset
- JSON format
- 200+ accounting questions and answers
- Easy to update and extend

---

## Technologies Used
- Python
- NLTK
- Scikit-learn
- TensorFlow

---

## Results
- Accurate responses
- Offline system
- Easy to maintain

---

## Conclusion
THis Project proves that classical AI methods can
successfully build real-world chatbots without APIs.
